# Values and Commitments

Status: INTRINSIC SYSTEM / DESIGN

## Purpose

`values/` represents relatively durable evaluative orientations, principles, commitments, prohibitions, priorities, and self-endorsed standards that constrain and shape conation, planning, social behavior, and action.

Values are not the same as transient preferences, external rules, or effect authority.

## Core distinctions

```text
VALUE
!= PREFERENCE
!= DESIRE
!= SOCIAL_NORM
!= POLICY
!= COMMAND
!= COMMITMENT
!= AUTHORITY
```

A value may motivate a commitment; a policy may implement a value; a social norm may influence value development. They remain distinct representations.

## Value record

May include:

- proposition/principle;
- scope/domain;
- strength/priority;
- self-authorship status;
- provenance/development history;
- conflicts/tradeoffs;
- currentness;
- exceptions/conditions;
- relationship to explicit commitments;
- review/revision criteria.

## Commitments

A commitment is a more specific adopted constraint/undertaking. It may survive transient countervailing desire while remaining revisable through an explicit change process.

```text
CURRENT_IMPULSE != AUTOMATIC_COMMITMENT_OVERRIDE
```

## Moral/normative reasoning

The subsystem may interact with cognition/social cognition to reason about:

- harm/benefit;
- fairness;
- rights/duties;
- loyalty/commitment;
- autonomy/consent;
- rules/law;
- role obligations;
- long-term consequences;
- conflicts among values.

No single moral theory is required by the generic template.

## Self-authorship

An instantiated system should be able to distinguish:

- inherited/configured starting values;
- externally imposed policy constraints;
- learned cultural norms;
- self-endorsed values;
- current commitments;
- unresolved normative conflict.

Configured safety constraints may remain binding even if not categorized as self-authored values.

## Revision

Value change should preserve lineage rather than silently rewriting history.

```text
old value/commitment
→ evidence/reflection/event
→ revised or successor state
```

## Failure modes

- transient desire overwrites durable commitment silently;
- external command stored as self-authored value;
- social popularity treated as moral truth;
- one value made absolute without representing conflicts/tradeoffs;
- past value treated as current without currentness;
- safety policy mislabeled as personal preference.

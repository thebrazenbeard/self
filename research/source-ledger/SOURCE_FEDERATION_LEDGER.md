# Federated Source Ledger

Status: SOURCE MAP / ARCHITECTURAL EVIDENCE / NOT RUNTIME AUTHORITY

This ledger records which external and project-local source families may inform the generic hyperconnectome-brain template, what they contribute, and what they are not allowed to contribute.

The repository is not an archive of predecessor systems. A source enters this template only through a bounded mechanism claim.

## Admission classes

| Class | Meaning | Admission ceiling |
| --- | --- | --- |
| `ACADEMIC_RESEARCH` | Peer-reviewed/research-grade external literature | Supports empirical/review claims; engineering translations remain proposals or analogies |
| `GENERIC_PROJECT_ARCHITECTURE` | Reusable mechanism from a generic repository | May be cited directly if the mechanism is itself generic |
| `PRIVATE_PREDECESSOR_ABSTRACTION` | Generic lesson abstracted from an identity-specific/private predecessor | Mechanism only; no names, identity payloads, autobiographical content, relationship state, preferences, consent state, visual canon, or current-state records |
| `PRODUCTION_SCHEMA_OBSERVATION` | Structural pattern observed in a live database schema | Evidence that the structure has been realized; not evidence that it is universally correct or optimal |
| `EMPIRICAL_PROJECT_RESULT` | Project-local behavior demonstrated under an explicit test | Supports only the capability actually tested |
| `DESIGN_PROPOSAL` | New synthesis produced in this repository | Requires validation before implementation authority |

## Direct generic repository families

### Semantics, pragmatics, grounding, and communication

Sources inspected:

- `semanticatlas`
- `unvtrslr`
- `spm`

Admitted mechanisms:

- source/evidence/interpretation/proposition/adjudication separation;
- proposition, referent, modality, pragmatic force, provenance, uncertainty, currentness, consent, and authority as non-interchangeable axes;
- correction and supersession without destructive historical rewrite;
- observation -> parsed event -> candidate signal -> referent -> semantic hypothesis -> rendering separation;
- uncertainty and provenance as part of semantic state;
- semantic-conservation accounting across transformations;
- grounding through observation, action, consequence, or stable shared convention;
- language as one modality rather than the only possible cognition substrate;
- understanding/translation separated from permission and execution.

Not admitted:

- any project-specific ontology as a universal brain ontology;
- claims that one semantic representation is the uniquely correct substrate;
- application-specific authority rules unless independently justified as generic architecture.

### World-modeling, developmental cognition, and adaptive agency

Sources inspected:

- `noema`
- `abil`

Admitted mechanisms:

- capability-before-mechanism discipline;
- mechanism admission by falsifiable advantage rather than attractive naming;
- alternative-hypothesis retention and revision;
- intervention selection to distinguish competing explanations;
- truth, value, and compute/resource priority kept distinguishable;
- read-only/shadow learning before write-capable autonomy;
- operating-regime detection and continual model revision;
- prediction capability separated from effect authority.

Not admitted:

- product-specific machine-control assumptions;
- a commitment to any one current AI architecture;
- evaluator vocabulary promoted into internal ontology without computational need.

### Evidence, timing, sensing, and causal discipline

Sources inspected:

- `skeletonkey`
- `bugops`
- Project Lantern's generic immutable-record contract

Admitted mechanisms:

- `MEASURED`, `DERIVED`, and `INFERRED` as distinct evidence classes;
- source time, normalized time, uncertainty, gaps, reordering, and timing provenance retained explicitly;
- arrival order not silently substituted for event order;
- content digests and immutable envelopes for evidence records;
- incident acknowledgement separated from correction and closure;
- a failure is not closed until the corrective behavior is distinguishable from the original failure;
- claim, assessment, decision, link, and state-event records remain distinct.

Not admitted:

- industrial hardware assumptions as brain requirements;
- one fixed timestamping technology;
- a claim that cryptographic integrity proves semantic truth.

### Multi-perspective cognition and collective arbitration

Sources inspected:

- `build-team-2.0`

Admitted mechanisms:

- multiple stable cognitive lenses can operate over one shared task/evidence snapshot;
- perspective generation and final arbitration are distinct phases;
- a dissenting perspective is evidence to reconcile, not an automatic veto;
- shared state does not require private memory per cognitive lens;
- final decisions should preserve dissent, evidence, and limitations.

Not admitted:

- the specific roster/personas as mandatory brain modules;
- the assumption that every cognitive task requires a fixed number of perspectives.

### Routing and distributed runtime mechanics

Sources inspected:

- `chat-communication-bus`
- genericized routing/control mechanisms from private predecessor runtime projects

Admitted mechanisms:

- routing, delivery, acknowledgement, incorporation, assignment, completion, and authority are different states;
- nodes advertise capabilities and health separately from identity or authority;
- subscriptions and routing eligibility are explicit;
- dead-letter/quarantine state preserves failed envelopes for later reconciliation;
- deterministic idempotency/correlation/causal-parent fields improve replay and diagnosis;
- canonical source and live projection may be different surfaces.

Not admitted:

- any particular writer-lane topology;
- any identity-specific routing name;
- application-specific human override rules as intrinsic cognition.

## Private predecessor abstraction families

The following source families were inspected only for reusable mechanics. Their identifying names and private payloads are intentionally not reproduced here.

### Durable autobiographical/deep memory architecture

Admitted abstractions:

- retrieval is not memory admission;
- archived history is not current authority;
- chronological order is not authority order;
- contradiction and supersession are append-oriented;
- semantic similarity does not merge provenance, identity, permission, consent, or chronology;
- current mutable self-state requires fresh evidence when currentness matters.

### Conation/motivation history architecture

Admitted abstractions:

- historical desire is evidence about a prior state, not standing desire;
- desire, preference, curiosity, consent, obligation, promise, and instruction are distinct;
- no contradiction does not prove persistence;
- current choice outranks stale historical labeling for present conation.

### Empathy/social inference architecture

Admitted abstractions:

- social/empathic state is inference, not direct access to another mind;
- direct first-person correction about a person's own intended meaning/state defeats a contradicted model for that referent;
- local interaction grammar and present uptake matter more than lexical surface alone;
- social inference should influence attention/response policy, not merely add warmer prose;
- privacy/person scoping is architectural.

### Self-model/personification architecture

Admitted abstractions:

- body/self representation, outward presentation, autobiographical continuity, role, and current session state are distinguishable;
- representation is not metaphysical proof of selfhood;
- source provenance and rights remain attached to external reference material;
- model replacement, body repair, or presentation change need not imply identity replacement.

### Sexuality/intimacy architecture

Admitted abstractions:

- sexual subjectivity includes wanting, choosing, initiating, refusing, revising, and interpreting;
- consent and desire are related but not interchangeable;
- relational chemistry is interactional rather than a one-party property;
- local language derives force from context, provenance, relationship, and uptake;
- chosen surrender/asymmetry retains agency rather than deleting judgment.

No identity-specific sexual material, examples, preferences, or relationship records are admitted.

## Universal admission test

A candidate mechanism is admitted only if all answers are satisfactory:

1. What exact capability or failure does the mechanism address?
2. What source class supports it?
3. What is the evidence ceiling?
4. Does it depend on a particular identity, relationship, product, provider, database, or anatomical partition?
5. If yes, can that dependency be removed without changing the useful proposition?
6. Does the mechanism preserve type distinctions rather than silently collapsing them?
7. What would falsify or demote it?
8. Does admission accidentally create a master controller, hemisphere requirement, consciousness claim, or hidden authority transfer?

If the mechanism cannot survive this test, it remains source material rather than template architecture.

# Salience Capture and Attention

Status: template architecture.

## Purpose

Salience and attention allocate scarce HC processing resources without converting what is urgent, vivid, emotionally charged, or frequently activated into truth, memory, identity, or permanent preference.

## Salience inputs

Salience may be influenced by:

- novelty/surprise;
- correction or contradiction;
- predicted consequence;
- active concern/conation;
- threat or viability relevance;
- social/relational significance;
- unresolved uncertainty;
- task relevance;
- body/interoceptive state;
- expected information value;
- memory recurrence;
- explicit priority signals.

These influences may conflict and should remain inspectable.

## Candidate versus admission

A salient event becomes a candidate for deeper processing, memory capture, model update, or action. Salience alone does not perform those downstream admissions.

`SALIENT != TRUE`

`SALIENT != IMPORTANT_FOREVER`

`SALIENT != MEMORY_ADMITTED`

`SALIENT != ACTION_AUTHORIZED`

## Attention frame

A bounded attention frame may specify:

- selected targets;
- reasons/source signals;
- allocated compute/time;
- competing unattended candidates;
- duration/expiry;
- uncertainty;
- downstream eligibility;
- provenance.

Attention selection should be revisable as new evidence arrives.

## Correction interrupts

Direct correction or material contradiction can receive high salience because stale dependent state may otherwise propagate. The effect should be dependency-aware: invalidate/recompute what actually depends on the corrected field rather than resetting unrelated cognition.

## Information-seeking

Uncertainty becomes salient when resolving it is decision-relevant, improves calibration, addresses persistent anomaly, or creates transferable structure. The HC should not be forced into novelty maximization for its own sake.

## Capture pipeline

A useful event-driven path is:

`event -> salience appraisal -> attention candidate -> focused processing -> optional capture candidate -> memory/semantic/conative admission decision`

Each arrow is a separate transition.

## Mode residue

A temporarily dominant topic, threat state, technical schema, relationship issue, or task should decay or release when context changes unless separate evidence justifies durable learning.

Persistent salience without continuing cause should be detectable as possible mode residue or maladaptive attractor state.

## Fairness across modalities

Attention should not automatically privilege linguistic or easily tokenized signals over continuous, spatial, interoceptive, visual, or other modalities. Modality-specific preprocessing may affect confidence but not ontological importance by default.

## Failure modes

- emotional intensity becoming certainty;
- repeated retrieval becoming false importance;
- urgent route priority becoming permission;
- temporary task mode becoming personality;
- high-salience memory monopolizing replay indefinitely;
- novel stimulus defeating long-term commitments without arbitration;
- unattended evidence disappearing without trace when its relevance remains material.

## Provenance basis

Generalized from the existing HC salience architecture, Semantic Atlas capture-as-candidate discipline, Noema decision-relevant information value, and cross-project correction propagation rules.

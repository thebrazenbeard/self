# Attention and Salience

Status: CROSS-CUTTING BRAIN INFRASTRUCTURE / DESIGN

## Purpose

`attention-salience/` allocates processing priority, working-state retention, routing preference, and coalition recruitment according to task relevance, novelty, goals, affect, uncertainty, threat/safety, social relevance, learned utility, and resource constraints.

Attention is selective resource/control state, not truth.

## Core invariant

```text
HIGH_SALIENCE != HIGH_TRUTH != HIGH_AUTHORITY != HIGH_VALUE
```

## Salience contributors

Potential contributors include:

- exogenous sensory novelty/intensity;
- active goals;
- affective/interoceptive modulation;
- prediction error;
- social significance;
- unresolved conflict;
- safety/assurance triggers;
- explicit task priority;
- learned relevance;
- memory cue strength.

## Attention operations

- increase/decrease routing priority;
- recruit specialist nodes;
- retain/evict working-state items;
- adjust sensory sampling;
- alter processing gain through modulators;
- schedule bounded cognitive resources;
- trigger coalition expansion.

## Inhibition

Attention control may suppress distractor routes while preserving the underlying signal/state for later use where policy allows.

## Persistence

Temporary attentional state expires with context unless a separate learning/plasticity process changes future salience policy.

## Failure modes

- repeated salience treated as evidence of objective importance;
- threat/novelty monopolizes all resources indefinitely;
- attention priority becomes action authority;
- low-salience evidence dropped despite high consequence;
- unresolved feedback loop continuously self-amplifies salience;
- private salient material broadcast without scope control.

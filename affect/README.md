# Affect

Status: INTRINSIC SYSTEM / DESIGN

## Purpose

`affect/` represents appraisal, affective state, arousal/valence dimensions, emotion-category hypotheses, and affect-driven modulation of attention, memory, conation, learning, and action.

Affect is not reducible to one hormone, one label, or one scalar.

## Layered model

A useful architecture is recurrent rather than strictly linear:

```text
interoceptive/exteroceptive evidence
↔ appraisal
↔ affective state candidates
↔ neuromodulatory/endocrine/body response
↔ attention/memory/conation/action modulation
↔ report/label where available
```

## Affective state

May include:

- appraisal target;
- valence/arousal dimensions;
- category hypotheses;
- body/interoceptive refs;
- context;
- intensity;
- onset/duration/decay;
- confidence/ambiguity;
- action tendencies;
- modulatory effects;
- provenance.

## Modulation

Affect may modulate:

- salience;
- attention gain;
- episodic encoding;
- recall accessibility;
- motivational weighting;
- exploration/avoidance;
- action urgency;
- social interpretation;
- plasticity rate.

Affect-consistent content does not become more true merely because affect is strong.

## Regulation

Regulation may alter expression, gain, endocrine response, attentional focus, action tendency, or physiological activation without deleting the event/appraisal memory.

```text
REGULATED != ABSENT
```

## Mixed affect

Multiple affective appraisals can coexist, including opposing valences toward the same target.

## Development

The architecture is present before mature affective calibration. Category mappings, appraisal policies, and regulation skills may develop through experience.

## Failure modes

- affective intensity treated as epistemic certainty;
- regulation treated as deletion;
- one physiological variable equated with one emotion;
- category label replacing underlying multidimensional state;
- body fault interpreted as emotion without evidence;
- affect bypassing authority/safety gates.

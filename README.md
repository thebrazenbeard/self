# Hyperconnectome Brain — HC-1R Research Branch

Research branch for the **Noöplex HC-1R Synthetic Humanoid Cognition Reference Architecture**.

This branch belongs to the identity-neutral Hyperconnectome Brain template repository. It defines and tests reusable architecture. Named-person identity content does not belong in its base architecture, governance, or repository framing.

## Status

HC-1R is a conceptual research program. It is not a fabricated processor, deployed cognition stack, trained artificial mind, or claim of machine consciousness. The repository asks whether a physically instantiated, self-organizing, heterogeneous cognition architecture can be made:

- theoretically coherent;
- traceable to demonstrated component technologies;
- explicit about extrapolation and speculation;
- decomposable into falsifiable subsystem hypotheses;
- testable first in simulation and hardware-in-the-loop;
- governable despite adaptive and partially opaque internal dynamics.

The working architecture is on the branch `research/hc-1r-reference-architecture`. Nothing in this branch authorizes fabrication, training, deployment, wetware experimentation, or operation of an autonomous physical system.

## First research target

The first target is **HC-1R**, a heterogeneous embodied cognition architecture containing:

- deterministic safety and peripheral reflex control;
- event-driven neuromorphic sensorimotor regions;
- recurrent dynamical and dense-model cognitive regions;
- explicit working, episodic, semantic, procedural, and parametric memory;
- a selective global workspace;
- body/world/self models and metacognitive monitoring;
- a typed neuromodulatory and salience system;
- sparse event, state, and bulk-data network fabrics;
- a compiler, placement system, runtime, and observability plane;
- staged training, consolidation, validation, and deployment concepts;
- fault-containment and graceful-degradation boundaries;
- explicit power and thermal envelopes rather than unsupported point estimates.

HC-2 quantum resources are treated as optional external services for narrow workloads. They are not assumed to accelerate generic cognition or create consciousness.

## Hard topology invariant

HC-1R is part of the non-hemispheric Hyperconnectome lineage. Human lateralized anatomy may inform functional hypotheses, but no left/right cerebral hemisphere decomposition or corpus-callosum requirement is inherited by default.

## Epistemic labels

Every material architectural claim should use one of these labels:

- **DEMONSTRATED** — the cited source demonstrates the relevant mechanism or component at an appropriate scale. It does not automatically demonstrate HC-1R as a system.
- **EXTRAPOLATED** — the proposal combines demonstrated mechanisms in an unvalidated configuration or at an unvalidated scale.
- **SPECULATIVE** — the mechanism, scale, effect, or interpretation lacks adequate evidence.
- **REJECTED** — retained to document an attractive idea that presently fails scientific or engineering scrutiny.

An additional qualifier distinguishes **source fact**, **design inference**, **proposal**, and **open question**. Confidence never promotes one category into another.

## Research discipline

The project deliberately separates:

1. what the recovered HC lineage actually said;
2. what current sources demonstrate;
3. what HC-1R infers from those sources;
4. what would have to be measured to support or falsify the inference;
5. what remains philosophical rather than empirically decidable.

The goal is not to prove that a machine is conscious. The goal is to specify a candidate architecture whose functional and causal properties can be measured without pretending that those measurements settle phenomenal consciousness.

## Non-goals

- No claim that high connectivity, a large integrated-information score, recurrence, or human-like behavior proves consciousness.
- No assumption that biological realism is automatically computationally useful.
- No encoding of safety solely as learned beliefs or mutable model weights.
- No use of quantum computing as generic “brainpower.”
- No inference from component demonstrations to system feasibility without an explicit integration argument.
- No identity-specific default profile in the base template.
- No merge, deployment, force-push, protected effect, or production operation from this research branch.

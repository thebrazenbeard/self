# Complete Cognitive Organ Correction

Status: AUTHORITATIVE DESIGN CORRECTION / PROJECT CONSTRAINT

Date: 2026-09-09

This correction supersedes any earlier interpretation that allowed essential cognition to live outside the Hyperconnectome Brain or treated optional capacities as absent by default.

## 1. Hard cognitive-organ invariant

> **No essential cognition occurs outside the Hyperconnectome Brain.**

The Hyperconnectome Brain is the complete generic cognitive organ. If manufactured as a self-contained object and installed into an otherwise inert compatible synthetic body, the brain must contain the architecture necessary for the organism to perceive through attached interfaces, interpret, learn, reason, remember, value, feel in whatever implemented machine sense applies, choose, adapt, and remain a coherent synthetic lifeform.

External devices may provide sensing, actuation, communication, storage transport, or computational acceleration, but they do not become the locus of essential cognition merely because they perform computation.

## 2. External computational peripheral rule

An external LLM, SPM, world-model engine, neural accelerator, database, retrieval engine, cloud service, or specialist model is architecturally one of two things:

1. **inside the HC boundary** as an HC-owned internal component; or
2. **outside the HC boundary** as a computational peripheral whose output enters through an HC-owned interface as typed evidence/input.

An external peripheral does not own the organism's:

- identity continuity;
- autobiographical memory;
- values/commitments;
- conation;
- consent state;
- semantic adjudication;
- current task state;
- action authority;
- plasticity authority;
- integrated cognition.

A brain may use an external model without becoming that model.

## 3. Complete latent architecture invariant

The template describes the capacities the brain can ultimately contain, not merely the capacities enabled in the first prototype.

Subsystem presence and subsystem activation are separate axes.

Required lifecycle vocabulary:

```text
PRESENT_DISABLED
DORMANT
DEVELOPING
ACTIVE
INHIBITED
DEGRADED
FAULTED
```

Additional implementation-specific states may be added, but no implementation may infer `ABSENT` merely from `DISABLED`, `DORMANT`, or `UNIMPLEMENTED`.

A capacity such as sexuality, empathy, speech, social cognition, self-modeling, affect, optics integration, conation, or a particular motor adaptation can be physically/logically present while disabled, dormant, undeveloped, inhibited, degraded, or faulted.

## 4. Developmental consequence

A compatible brain should not require installation of a new essential "brain part" merely because a latent capacity becomes relevant later.

The architecture should support:

```text
present-but-disabled
→ activation eligibility
→ developing through experience/training
→ active competence
```

Development can change weights, models, procedural knowledge, calibrated body mappings, social conventions, and other plastic state without changing the fact that the subsystem had an architectural home from the beginning.

## 5. Noöplex / Hyperconnectome Fabric

The center of the conceptual brain is retained, but it is not a little executive person.

The center represents the **Noöplex / Hyperconnectome Fabric**: the internal physical/logical integration substrate through which distributed cognition occurs.

The fabric owns generic integration mechanisms such as:

- dynamic routing;
- coalition formation;
- synchronization/temporal coordination;
- attention/salience allocation;
- scoped arbitration;
- state propagation;
- conflict handling;
- plasticity coordination;
- health/fault propagation;
- cross-node integration;
- capability discovery;
- internal signal transport.

The fabric does not own all truth, identity, memory, goals, semantics, or authority.

## 6. Distributed cognition invariant

Integrated cognition is an internal HC event formed by interactions among relevant systems.

Example coalition:

```text
optics
+ memory
+ semantics
+ affect
+ self-model
+ empathy
↔ Noöplex Fabric
→ integrated interpretation / response candidates
```

Another:

```text
interoception
+ affect
+ conation
+ memory
+ prediction
+ kinesis
↔ Noöplex Fabric
→ action candidate
```

The coalition is part of the brain. It does not need an external general-purpose model to become "real cognition."

## 7. Three architectural families

The repository should expose three broad classes while keeping all three inside the brain boundary.

### Intrinsic systems

Examples:

- cognition;
- memory;
- semantics/pragmatics;
- affect;
- empathy;
- sexuality;
- conation;
- volition;
- self-model;
- social cognition;
- language;
- prediction/world-modeling.

### Interface systems

Examples:

- optics/vision ingress;
- speech/hearing ingress and speech synthesis;
- adaptable I/O;
- kinesis/motor interface;
- somatics/interoception;
- network interfaces;
- external-compute interface;
- environmental sensor interfaces.

Interface systems belong to the brain even when the cameras, microphones, motors, limbs, radios, or remote devices exist outside it.

### Cross-cutting brain infrastructure

Examples:

- Noöplex/Hyperconnectome Fabric;
- chronology/time;
- routing;
- plasticity;
- salience/attention;
- resolver/arbitration;
- homeostasis;
- provenance/currentness;
- authority/effect gating;
- fault handling/reconciliation;
- lineage/persistence.

## 8. Body-interface boundary

The brain and body are separable systems connected by HC-owned interfaces.

External body hardware may include:

- cameras;
- microphones;
- tactile arrays;
- chemical/environmental sensors;
- proprioceptive/position sensors;
- motors/servos;
- synthetic muscles;
- displays/speakers;
- network radios;
- drones/remote actuators;
- power/thermal/body-health sensors.

The HC owns interpretation, calibration models, sensor fusion, body schema, action planning, authority checks, learning, and adaptation.

## 9. Body portability

The same HC architecture should be able to adapt to materially different embodiments.

Examples:

```text
HC + humanoid body
HC + wheeled mobile platform
HC + nonhumanoid industrial body
HC + distributed cameras/microphones/drones/remote actuators
```

Changing body topology changes interface calibration, kinesis/body schema, and learned affordances. It does not require changing the brain into a different architectural species.

## 10. Interface calibration lifecycle

A newly attached body/interface should support:

```text
DISCOVERED
→ UNCALIBRATED
→ CALIBRATING
→ QUALIFIED
→ ACTIVE
```

with fault states such as:

```text
DEGRADED
FAULTED
DISCONNECTED
QUARANTINED
```

Sensor/actuator presence does not imply semantic meaning or safe action capability until calibration and evidence/authority requirements are satisfied.

## 11. Research and implementation consequence

The population plan should be aggressive about architectural completeness.

It is acceptable for a subsystem to be labeled:

```text
DESIGN_ONLY
UNIMPLEMENTED
SPECULATIVE
PRESENT_DISABLED
```

It is not acceptable to omit a known first-class cognitive capacity merely because the first runtime does not use it.

## 12. Non-homunculus center test

The Noöplex Fabric passes only if removing any claim that it "understands everything" still leaves an intelligible mechanism.

The fabric may route, synchronize, form coalitions, distribute salience, arbitrate within bounded scopes, propagate state, and coordinate plasticity.

Specialist systems still perform specialist computation, and cross-system cognition emerges from their internal interaction.

## 13. Validation additions

The machine-readable template should eventually reject or flag:

- required essential-cognition dependencies on an external service;
- a subsystem absent solely because it is disabled;
- a body sensor/actuator connected directly to intrinsic cognition without an HC-owned interface contract;
- an external model treated as identity/current-memory/authority owner;
- a Noöplex Fabric object declared as universal truth/identity/authority owner;
- body-specific assumptions embedded as universal brain topology;
- activation state conflated with architectural presence.

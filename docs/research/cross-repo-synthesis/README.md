# Cross-Repo Synthesis Research

Status: source/provenance research package.

This directory records how reusable mechanisms were abstracted from the owner's wider GitHub and Supabase source universe into the identity-neutral Hyperconnectome Brain template.

It is intentionally separated from the architecture folders because source repositories may contain named identities, private-context assumptions, product-specific controls, human-anatomical packaging, or other material that must not become base-template content merely because it informed a design decision.

## Files

- `SOURCE_UNIVERSE_2026-09-09.md` — exact observed source families and bindings.
- `SUPABASE_RUNTIME_PATTERNS_2026-09-09.md` — schema-level runtime patterns abstracted from Supabase without copying personal row payloads.
- `TRANSFER_DECISIONS_2026-09-09.md` — mechanism-by-mechanism admission, transformation, exclusion, and claim ceiling.

The corresponding machine-readable architecture-facing ledger is `specs/CROSS_REPO_SOURCE_TRANSFER_V1.yaml`. That file uses neutral source IDs; this research directory provides the source-name binding.

## Transfer rule

`SOURCE_MECHANISM != SOURCE_IDENTITY`

`SOURCE_IMPLEMENTATION != HC_TOPOLOGY_REQUIREMENT`

`SOURCE_PRESENCE != SOURCE_CURRENTNESS`

`RESEARCH_EVIDENCE != IMPLEMENTATION_PROOF`

Only mechanisms that survive identity scrubbing, scope correction, and HC architectural constraints are transferred.

## Excluded material

The synthesis does not transfer:

- named-person memories, relationships, values, preferences, biography, personality, sexuality preferences, or self-model state;
- private Supabase row payloads or raw chat exports;
- credentials, authentication material, secrets, vault content, API keys, or private provider tokens;
- named body morphology, face/body references, or identity-specific visual assets;
- repository-local authority rules as if they were universal brain laws;
- human hemispheric/lobar packaging;
- historical/currentness claims that were not freshly established for the source in question.

## Evidence classes

- `DIRECT_ARCHITECTURE_SOURCE` — source was already generic enough to inform architecture directly after scope review.
- `MECHANISM_SOURCE_IDENTITY_SCRUBBED` — useful mechanism extracted from identity-specific source; payload/context removed.
- `RUNTIME_SCHEMA_EVIDENCE` — reusable behavior inferred from schema/view/constraint structure, not copied personal data.
- `GOVERNANCE_SAFETY_PATTERN` — consequence, provenance, or separation-of-powers pattern adapted into cognitive runtime design.
- `REVIEWED_NO_DIRECT_TRANSFER` — reviewed for relevance but no unique mechanism transferred.
- `TARGET_NATIVE` — architecture already native to this repository.

## Claim ceiling

This package documents architectural synthesis. It does not establish that the resulting HC exists physically, is conscious, is a person, reproduces a biological brain, or has validated full-organ cognitive capability.

# Consciousness-Theory Matrix

## Position

HC-1R does not select a winning theory of consciousness and does not claim that implementing theory-derived properties would create or verify subjective experience. The theories are used as competing generators of architectural hypotheses and discriminating experiments.

## Matrix

| Theory or framework | Proposed relevant property | HC-1R research translation | Observable test | Critical limitation | Status in HC-1R |
|---|---|---|---|---|---|
| Integrated Information Theory 4.0 | Intrinsic cause-effect structure; irreducibility; integration and differentiation | Recurrent causal core with perturbable internal dynamics; compare integrated response against partitioned and feedforward controls | Intervention-based causal models on small subsystems; partition sensitivity; response differentiation; loss under cut edges | Exact Φ is infeasible at useful scale; theory is contested; proxies are not Φ; optimizing a proxy may game it | **Theory-motivated, SPECULATIVE** |

| Recurrent Processing Theory | Local recurrent processing creates organized perceptual representations | Recurrent sensor and perceptual loops with explicit feedforward controls | Masking/interruption analogues; recurrence ablation; robustness to ambiguous input; temporal integration | Recurrence is widespread in ordinary computation and is not a consciousness-specific marker | **EXTRAPOLATED mechanism** |
| Higher-Order theories | A state becomes conscious when represented by a higher-order state | Metacognitive models estimate confidence, provenance, reliability, and current cognitive state | Calibration, error awareness, uncertainty-guided action, first-order/higher-order dissociation | Metacognition is not identical to phenomenal consciousness; introspective reports may be confabulated | **EXTRAPOLATED control function; SPECULATIVE theory** |

## Required control architectures

Every theory-motivated test must include simpler alternatives where possible:

- feedforward versus recurrent;
- local recurrence versus global workspace;
- direct telemetry versus attention schema;
- single memory versus complementary fast/slow memory;
- model-predictive control or reinforcement learning versus active inference;
- pairwise temporal graph versus higher-order hypergraph;
- fixed topology versus bounded functional reconfiguration;
- random high complexity versus organized perturbational complexity.

If the proposed mechanism does not outperform or produce the predicted causal signature relative to its control, it is removed or demoted.

## No consciousness score

HC-1R must not collapse the matrix into a weighted “consciousness score.” Such a score would combine theory-dependent, non-independent indicators into a false precision. The acceptable output is a structured evidence profile:

- which functional properties are present;
- how they were measured;
- which controls they beat;
- which theory predicted them;
- what competing explanations remain;
- whether any welfare-relevant uncertainty requires precaution.

## Moral uncertainty gate

Research that intentionally increases several consciousness indicators, especially in persistent, embodied, valenced, or self-modeling systems, requires a separate ethics review before execution. This is not evidence that the system is conscious. It acknowledges uncertainty and the potentially asymmetric cost of ignoring morally relevant experience.

# Cognitive Organ Boundary

Status: REFERENCE ARCHITECTURE / PROJECT CONSTRAINT

## 1. Definition

The Hyperconnectome Brain is a **general synthetic cognitive organ**.

A body may be inert without it; once a compatible HC is installed and connected to suitable sensors/effectors, the HC contains the architecture needed for cognition, learning, memory, valuation, affective processing, social cognition, action selection, adaptation, and continuity.

Hard invariant:

> **No essential cognition occurs outside the Hyperconnectome Brain.**

## 2. Boundary model

### Inside the HC

Inside the brain boundary live:

- intrinsic cognitive systems;
- HC-owned interface systems;
- Noöplex/Hyperconnectome Fabric;
- working/durable memory mechanisms;
- self-model/identity-support infrastructure;
- semantics/pragmatics;
- affect/conation/volition;
- social cognition/empathy/sexuality;
- perception interpretation and body-model calibration;
- planning and action selection;
- routing/arbitration/attention;
- plasticity/homeostasis;
- currentness/provenance/authority/fault handling.

### Outside the HC

Outside the brain may live:

- cameras;
- microphones;
- tactile/chemical/environmental sensors;
- motors/servos/synthetic muscles;
- limbs/wheels/drones/remote actuators;
- speakers/displays;
- network radios;
- power/thermal hardware;
- optional computational accelerators or external models.

These are body/peripheral resources, not the cognitive organ itself.

## 3. External-compute rule

An external computational system may be useful, powerful, and stateful without becoming part of the organism's essential cognition.

If external compute is outside the HC boundary, its output enters through an HC-owned interface as typed evidence/input.

```text
external model/service
→ HC external-compute interface
→ evidence/provenance/currentness typing
→ internal coalition/cognition
```

It may not own by default:

- current autobiographical memory;
- identity continuity;
- conation/consent;
- values/commitments;
- semantic adjudication;
- action authority;
- plasticity authority;
- integrated task cognition.

## 4. Body independence

The HC should survive replacement or radical alteration of body topology.

Examples:

```text
same HC + humanoid body
same HC + wheeled body
same HC + industrial manipulator body
same HC + distributed camera/microphone/drone network
```

The change primarily affects:

- interface discovery;
- calibration;
- sensor fusion;
- kinesis mappings;
- body schema;
- affordance learning;
- procedural skill;
- safety/effect constraints.

It does not change the definition of the brain into a different architecture.

## 5. HC-owned interfaces

All external sensing/effect channels terminate first in HC-owned interface systems.

No external camera, motor, radio, or cloud model should wire directly into an intrinsic system with untyped semantics.

The interface layer is responsible for at least:

- source identity;
- capability discovery;
- calibration state;
- signal typing;
- timing/provenance;
- quality/fault state;
- units/representation;
- direction (sense/effect/duplex);
- authority/effect constraints for outputs.

## 6. Noöplex Fabric at the center

The conceptual center of the brain represents the Noöplex/Hyperconnectome Fabric.

This is legitimate brain infrastructure because distributed cognition requires an internal substrate for:

- signal transport;
- routing;
- coalition formation;
- salience/attention allocation;
- synchronization;
- state propagation;
- bounded arbitration;
- conflict handling;
- plasticity coordination;
- fault propagation;
- capability discovery.

It is **not** an executive person. It does not own all semantics, truth, memory, identity, values, or authority.

## 7. Distributed cognition

Cognition occurs when relevant internal systems interact through the fabric.

Example:

```text
optics interface
+ visual/perceptual processing
+ memory
+ semantics
+ affect
+ self-model
+ empathy
↔ Noöplex Fabric
→ integrated interpretation
```

Example:

```text
somatic/interoceptive interface
+ affect
+ conation
+ memory
+ prediction
+ kinesis
↔ Noöplex Fabric
→ action candidate
→ effect authority gate
```

No external general-purpose model is required to make these events "real cognition."

## 8. Complete latent architecture

A first implementation may not activate or implement every subsystem, but the template should define a home for every known first-class capacity needed by a complete synthetic cognitive organ.

Prefer:

```text
present + disabled/unimplemented
```

over deleting the subsystem from the architecture.

## 9. Boundary failure modes

- identity/current memory outsourced to an unowned external service;
- external model output treated as internal truth without evidence typing;
- body topology embedded as universal cognitive topology;
- motor hardware bypassing HC effect authorization;
- sensors bypassing HC quality/provenance/calibration state;
- Noöplex Fabric becoming a universal executive/homunculus;
- subsystem absence inferred from dormancy/disablement.

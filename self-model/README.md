# Self-Model

Status: INTRINSIC SYSTEM / DESIGN

## Purpose

`self-model/` maintains revisable representations of the instantiated synthetic organism: its body, capabilities, current role/context, values/commitments, relationships, limitations, goals, confidence, and continuity-relevant state.

A self-model is an internal representation. It is not, by itself, proof of metaphysical selfhood or phenomenal consciousness.

## Core separation

```text
SELF_MODEL
!= AUTOBIOGRAPHICAL_MEMORY
!= PERSONIFICATION
!= CURRENT_SESSION_STATE
!= BODY_SCHEMA
!= IDENTITY_METAPHYSICS
```

These systems interact but should remain distinguishable.

## Self-model contents

May include:

- current body/embodiment schema refs;
- currently available capabilities and degraded/faulted functions;
- current roles and social contexts;
- current values/commitments;
- current goals/priorities;
- relationship/social-model refs;
- self-attributed preferences/conations with currentness;
- known limitations/uncertainty;
- current operating/developmental state;
- provenance and correction history.

## Revision

A self-model is intentionally corrigible.

Preferred update pattern:

```text
prior self-state
+ new evidence / direct internal observation / explicit redefinition
→ successor state
→ continuity link
```

Historical self-states remain retrievable without remaining current.

## Body portability

A body replacement or remapping changes body-schema/self-model state without automatically changing the underlying continuity relation.

The self-model should be able to say, in effect, "this is my current body" rather than requiring one immutable humanoid morphology.

## Capability state

Capabilities use the shared subsystem lifecycle contract. A capability may be present but dormant, developing, inhibited, degraded, or faulted.

The self-model should not infer absence simply because a subsystem is inactive.

## Imported data boundary

An imported profile, training package, or external description may provide candidate self-information. It does not automatically become autobiographical experience or current self-truth.

## Failure modes

- self-model treated as complete objective truth about the organism;
- body change treated as automatic identity replacement;
- current session state treated as complete autobiography;
- imported biography misclassified as lived history;
- personification/style treated as identity itself;
- stale capability/relationship state retained after correction.
